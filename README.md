# 雪夜居酒屋 · 微缩景观

一个完全离线运行的单文件 Three.js 场景，采用三渲二卡通材质、描边与冷暖对比布光，构建在完整正方形纯色底座上的可收藏级雪夜居酒屋微缩模型。

## 打开方式

直接双击 `index.html`（或 `snow-izakaya.html`）在支持 WebGL2 的桌面浏览器中打开。不需要服务器，也不依赖任何外部资源。

- 鼠标左键拖动：环绕旋转
- 滚轮 / 双指捏合：缩放
- 画面内没有任何按钮、文字或控制条

## 场景内容

- 自下而上的分层组装入场动画，最后开启飘雪、炊烟与暖光
- 月夜雪山与远处城镇灯火背景，强风斜向暴雪、近景雪絮与景深光斑
- 持续强风斜雪、烟囱与炭炉白烟、被风吹动的暖帘与红灯笼
- 随机缓慢开合的木质格子推拉门与暖色室内
- 屋顶厚雪、冰凌、木质“居酒屋”招牌、深蓝“焼き鳥”暖帘
- “麦酒”“焼き鳥”红灯笼、石灯笼、暖光路灯、白色复古摩托车
- 酒樽、手写菜单立牌、木桶、雪松、枯枝灌木、脚印与车轮辙印

## 重新构建

```bash
npm install
npm run build
```

构建会重新生成 `index.html` 与 `snow-izakaya.html`。
